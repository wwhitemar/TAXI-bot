# TAXI-bot

## О проекте
TAXI-bot — это Telegram-бот, разработанный для упрощения заказа такси. Проект позволяет пользователям быстро находить и бронировать такси, указывая точку отправления и назначения, а также получать информацию о стоимости поездки и ETA (примерное время прибытия). Бот создан как pet-проект для демонстрации навыков программирования и работы с API.

## Основные функции
- **Заказ такси:** Укажите начальную и конечную точки через текстовые команды или геолокацию.
- **Расчет стоимости:** Интеграция с внешним API для оценки цены поездки.
- **Статус поездки:** Уведомления о статусе (поиск машины, водитель в пути, завершение).
- **Простота использования:** Интуитивный интерфейс с поддержкой команд и кнопок.

## Используемые технологии
- **Язык программирования:** Python
- **Библиотеки:**
  - `pyTelegramBotAPI` — для взаимодействия с Telegram API.
  - `requests` — для работы с внешними API (например, карт или такси-сервисов).
- **API:** Пример интеграции с API карт (Google Maps, Яндекс.Карты) или такси-сервисов.
- **Хостинг:** Локальный запуск или деплой на Heroku/VPS.

## Установка и запуск
1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/wwhitemar/TAXI-bot.git
   ```
2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
3. Создайте файл `.env` и добавьте токен Telegram-бота:
   ```
   TELEGRAM_TOKEN=ваш_токен_от_BotFather
   ```
4. Запустите бота:
   ```bash
   python bot.py
   ```

## Структура проекта
- `bot.py` — основной файл с логикой бота.
- `requirements.txt` — список зависимостей.
- `.env` — файл с конфиденциальными данными (не включен в репозиторий).
- `README.md` — документация проекта.

## Пример использования
1. Запустите бота и отправьте команду `/start`.
2. Введите точку отправления и назначения, например:  
   `От: ул. Ленина 10, К: вокзал`.
3. Получите ответ с примерной стоимостью и временем ожидания.
